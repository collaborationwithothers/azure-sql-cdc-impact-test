# Verification: Container Apps, Event Hubs, pricing, budgets, GitHub

Checked: 2026-11-22 by the documentation-verification agent, against Microsoft
Learn and GitHub docs. Live API reads by this session are marked "observed".

## Container Apps jobs
Sources: https://learn.microsoft.com/azure/container-apps/jobs,
https://learn.microsoft.com/azure/container-apps/tutorial-event-driven-jobs

- Manual trigger: VERIFIED.
- `replicaRetryLimit` 0 fails a replica without retrying: VERIFIED.
- `replicaTimeout` maximum: UNVERIFIABLE. No documented maximum. The harness
  must not depend on one; the spike measures it.
- User-assigned identity pulling from ACR Basic: VERIFIED.
- Job pinned to a dedicated workload profile (`workloadProfileName`): VERIFIED
  at API level.
- `az containerapp job start`, `az containerapp job execution list`: VERIFIED.
- Several containers in one job is "an advanced scenario": VERIFIED.
- Platform maintenance "might interrupt long-running job replicas": VERIFIED.
  Microsoft advises a retry limit of at least 1. This design keeps 0 on purpose
  (section 5): an interrupted benchmark is marked failed, not retried.

## Event Hubs
Sources: https://learn.microsoft.com/azure/event-hubs/azure-event-hubs-apache-kafka-overview,
https://learn.microsoft.com/azure/event-hubs/event-hubs-scalability,
https://learn.microsoft.com/azure/event-hubs/authenticate-managed-identity

- Kafka endpoint on Standard, not Basic: VERIFIED.
- One throughput unit is 1 MB/s or 1,000 events/s ingress, whichever first:
  VERIFIED. Up to 40 per Standard namespace. Auto-inflate scales up only.
- Kafka clients can use Entra ID through SASL OAUTHBEARER; Microsoft publishes
  a Java managed identity callback sample
  (https://github.com/Azure/azure-event-hubs-for-kafka/tree/master/tutorials/oauth/java/managedidentity):
  VERIFIED.
- Roles "Azure Event Hubs Data Sender" and "Data Receiver" can be assigned at
  resource group scope: VERIFIED.
- SAS can be disabled (`disableLocalAuth`): VERIFIED.
- Max event size on Standard 1 MB: VERIFIED.
- Kafka compression is Premium and Dedicated only: VERIFIED. Do not set
  `compression.type` on Standard.

## Retail Prices API
Source: https://learn.microsoft.com/rest/api/cost-management/retail-prices/azure-retail-prices

- Endpoint `https://prices.azure.com/api/retail/prices`, no authentication,
  OData `$filter`, pages of 1,000: VERIFIED.
- Compute product: `SQL Database Single/Elastic Pool General Purpose - Compute Gen5`.
  Zone redundancy has its own meter, `Zone Redundancy vCore`. Inference, not
  documented: it is billed on top of the `vCore` meter.
- Storage product: `SQL Database Single/Elastic Pool General Purpose - Storage`,
  with a separate zone redundancy storage meter.
- Filter `priceType eq 'Consumption'` and dedupe by meter ID.
- The report reads prices at report time. No price is written into docs.

## Federated credential and OIDC subject
Sources: https://learn.microsoft.com/entra/workload-id/workload-identity-federation-considerations,
https://docs.github.com/actions/reference/security/oidc

- Issuer `https://token.actions.githubusercontent.com`, audience
  `api://AzureADTokenExchange`: VERIFIED. Subject must match exactly.
- Repositories created after 2026-07-15 use an immutable subject format with
  owner and repository IDs: VERIFIED.
- Observed 2026-11-22: this repository uses the immutable format. Its subject
  prefix is read from
  `GET /repos/{owner}/{repo}/actions/oidc/customization/sub` at bootstrap time.
  The environment form is assumed to be `<prefix>:environment:azure`. That
  form is not documented and is confirmed by the first workflow sign-in.

## GitHub environment secrets
Sources: https://docs.github.com/rest/actions/secrets,
https://docs.github.com/actions/how-tos/deploy/configure-and-manage-deployments/manage-environments

- PARTIAL. Configuring an environment in an organization repository needs admin
  access. The REST secrets page says collaborator access and the `repo` scope.
  The docs do not state the exact level for environment secrets. This repo
  treats repository admin as required.
